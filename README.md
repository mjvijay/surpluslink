# 🌱 SurplusLink — Community Surplus Food Rescue Platform

SurplusLink is a full-stack web application that connects people and organizations with surplus food (**Donors**) to NGOs, shelters, and volunteers who collect and distribute it (**Receivers**), overseen by a platform **Admin**.
